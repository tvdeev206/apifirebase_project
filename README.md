# ReNO AI Notes 🧠

ReNO là một ứng dụng ghi chú thông minh tích hợp AI, cho phép người dùng tạo, chỉnh sửa và xử lý nội dung ghi chú bằng lệnh `/ReNO` thông qua Google Gemini API, kết hợp FastAPI backend và frontend HTML.

---

## Tech Stack

- Frontend: HTML, TailwindCSS, JavaScript (Vanilla)
- Backend: FastAPI (Python)
- AI Engine: Google Gemini API
- Authentication (optional): Firebase Auth
- Database (optional): Firestore
